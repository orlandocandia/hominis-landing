1. Introduccion al Sistema

Todo lo que necesitas saber sobre tu sistema de gestion web

1.1 Que es el sistema

El sistema es una pagina web profesional (landing page) diseñada para que los potenciales clientes de Hominis puedan conocer los planes de salud, ver las promociones vigentes y solicitar asesoramiento completando un formulario online.

Cuando un cliente completa el formulario, sus datos se guardan automaticamente en una base de datos y te llega una notificacion por email con toda la informacion para que puedas contactarlo rapidamente.

📋 Formulario Online

Los clientes te contactan las 24 horas, los 7 dias de la semana.

📧 Notificacion por Email

Recibis los datos del cliente directo en tu casilla de correo.

💾 Base de Datos

Todos los contactos quedan guardados para consulta posterior.

🔐 Panel de Admin

Gestionas los contactos, cambias estados y eliminas registros.

1.2 Para quien esta pensado

El sistema esta pensado para Agustina C. Candia, asesora comercial de Hominis, como herramienta de captacion de clientes y gestion de contactos. Los visitantes del sitio son personas interesadas en contratar un plan de salud.

1.3 Requisitos para usarlo

Para usar el sistema solo necesitas:

  • Un navegador web (Chrome, Firefox, Safari, Edge - actualizado)
  • Conexion a internet
  • Tu email configurado para recibir notificaciones
  • Tus credenciales de acceso al panel de administracion
CONSEJO

El sitio funciona tanto en computadora como en celular. La pagina se adapta automaticamente al tamano de la pantalla.

3.2 Que pasa despues de enviarlo

Cuando el cliente presiona el boton "Enviar Solicitud", el sistema realiza automaticamente lo siguiente:

1. El cliente completa el formulario
↓
2. El sistema valida los datos
↓
3. Se guardan en la base de datos (Turso)
↓
4. Te llega un email con todos los datos
↓
5. El cliente ve un mensaje de confirmacion
TIEMPO DE RESPUESTA

La pagina le indica al cliente: "Completá el formulario y me comunico con vos en menos de 24 horas." Trata de responder lo antes posible para maximizar la conversion.

3.3 Campos obligatorios y opcionales

Los campos marcados con * son obligatorios. Si el cliente intenta enviar el formulario sin completarlos, el navegador le mostrara un mensaje de error y no se enviara.

Los campos opcionales (Edad, Cobertura de interes, Mensaje) ayudan a que tengas mas informacion para la asesoria, pero no bloquean el envio.

PROTECCION ANTI-SPAM

El sistema tiene proteccion contra envios masivos. Si alguien intenta enviar el formulario muchas veces desde la misma conexion, se bloqueara temporalmente. Esto protege tu casilla de email de spam.

Una vez autenticada, podes consultar los contactos a traves de la API del sistema. Los contactos se pueden filtrar por:

  • Segmento: RECIBO_DE_SUELDO, MONOTRIBUTO, PARTICULAR
  • Busqueda: por nombre, email, telefono o mensaje

Los contactos se muestran ordenados del mas reciente al mas antiguo, con paginacion de 20 contactos por pagina.

7. Preguntas Frecuentes

Las dudas mas comunes resueltas

¿No me llega el email cuando un cliente completa el formulario?

Verifica lo siguiente:

  1. Revisa la carpeta de Spam o Correo no deseado en tu casilla Gmail
  2. Asegurate de que el cliente completo todos los campos obligatorios
  3. El email viene de la direccion: onboarding@resend.dev
  4. Si el problema persiste, contacta a soporte tecnico

¿Puedo cambiar el horario de atencion que aparece en la web?

Si, pero requiere modificar el codigo del sitio. Actualmente muestra "Lunes a Viernes: 9:00 - 18:00" y "Sabados y Domingos: Cerrado". Para cambiarlo, contacta a soporte tecnico.

¿Puedo agregar o modificar los planes de salud?

Si, pero los planes estan definidos en el codigo de la pagina. Para agregar, modificar o eliminar planes, se necesita editar el archivo del sitio web y volver a publicar. Contacta a soporte tecnico para hacer estos cambios.

¿Que pasa si se cae el sitio web?

El sitio esta alojado en Vercel, una plataforma con un 99.99% de disponibilidad. Si el sitio no carga, suele ser un problema temporal de DNS. Espera unos minutos e intenta nuevamente. Si el problema persiste mas de una hora, contacta a soporte.

¿Los datos de los clientes estan seguros?

Si. Los datos se guardan en Turso, una base de datos en la nube con cifrado. Ademas, el formulario tiene proteccion CSRF y limitador de tasa para evitar accesos no autorizados. Solo vos podes ver los contactos a traves del panel de administracion con tu contraseña.

¿Puedo recibir notificaciones por WhatsApp?

Actualmente las notificaciones automaticas son solo por email. Sin embargo, el email que recibis incluye un boton verde que abre WhatsApp directamente con el cliente, asi que con un solo clic podes contactarlo por WhatsApp.

La notificacion automatica por WhatsApp esta disponible como funcionalidad futura, pero requiere configuracion adicional (obtener una API key de CallMeBot enviando "AllowMe" al +34644452906).

¿Como cambio mi contraseña del panel de administracion?

Actualmente, el cambio de contraseña requiere acceso tecnico al sistema. Contacta a soporte para cambiarla.

¿El sitio funciona sin internet?

No. El sitio requiere conexion a internet tanto para que los clientes lo visiten como para que recibas las notificaciones. Sin embargo, los datos ya guardados en la base de datos no se pierden si se corta el internet.
